あなたの視聴分析

「見た」作品を対象に、各シーズンを別作品として集計します。同じシリーズを複数期見ると、その分も加算されます。視聴本数は、好みの広がりと必ずしも一致しません。

制作会社ランキング

複数社制作の作品は、それぞれの制作会社に1作品として集計します。

あなたの視聴傾向

ジャンルと作品の特徴は別々に集計します。1作品に複数の分類が付くことがあります。

作品詳細

作品情報は Tenrai API から取得しています。未登録の項目は表示しません。作品概要は日本語版Wikipediaの公開情報を補完に利用することがあります。PVの公開状況や日本国内の配信状況は保証されません。
